# پکیج‌های قالب

نسخهٔ پکیج‌های انتخاب‌شده از `HastYaNist/ui` گرفته شده و نسخه‌های حل‌شده در
`pnpm-lock.yaml` ثبت شده‌اند.

| گروه        | پکیج‌ها و کاربرد                                                                          |
| ----------- | ----------------------------------------------------------------------------------------- |
| اجرای وب    | React، React DOM، React Router، Vite، TypeScript و React Compiler                         |
| رابط کاربری | Chakra UI و Emotion برای اجزا و تم، next-themes برای حالت روشن و تاریک، Lucide برای آیکون |
| زبان        | i18next و react-i18next برای ترجمه و تغییر جهت فارسی و انگلیسی                            |
| داده        | Axios برای HTTP و TanStack Query برای کش، وضعیت درخواست و تلاش دوباره                     |
| فرم         | React Hook Form، Zod و @hookform/resolvers برای مدیریت فرم و اعتبارسنجی داده              |
| کیفیت       | ESLint و Prettier، Vitest و Testing Library، Playwright برای تست مرورگر                   |

## گزینه‌ها برای تصمیم بعدی

| پکیج                                                                             | چه زمانی کاربرد دارد                                                                                |
| -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| [motion](https://motion.dev/docs/react)                                          | وقتی صفحه به انیمیشن چیدمان یا ورود و خروج اجزا نیاز دارد؛ مثلاً جابه‌جایی نرم کارت‌های یک داشبورد. |
| [echarts](https://echarts.apache.org/en/index.html)                              | وقتی داشبورد گزارش‌گیری به نمودار تعاملی، فیلتر یا بزرگ‌نمایی نیاز دارد.                            |
| [@tanstack/react-virtual](https://tanstack.com/virtual/latest/docs/introduction) | وقتی فهرست بسیار بلند است و رندر کردن فقط ردیف‌های قابل مشاهده پیمایش را روان‌تر می‌کند.            |
| [vite-plugin-pwa](https://vite-pwa-org.netlify.app/guide/)                       | وقتی نصب اپ از مرورگر یا رفتار آفلاین جزو نیازهای پروژه است.                                        |

پکیج‌های این بخش اختیاری‌اند و در وابستگی‌های مستقیم قالب اضافه نشده‌اند.
