## دامنه

ساخت یک پروژهٔ وب مستقل با ساختار پوشه‌ها، قراردادهای کدنویسی، ابزارهای توسعه و اجزای مشترک رابط کاربری. یک مسیر نمونه الگوی اتصال صفحه، فرم، فیلتر URL و API را نشان می‌دهد. قراردادهای بک‌اند، قابلیت‌های تجاری، برند و تنظیمات انتشار به پروژهٔ مبدأ وابسته‌اند.
